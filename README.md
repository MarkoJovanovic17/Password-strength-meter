# Password Strength Meters vs. Simulated Attackers

Course project for *Network and Information Systems Security* at Iscte – Instituto Universitário de Lisboa.

**Team:** Rayan Ainouche, Marko Jovanovic, Valentine Germain, Ilyes Adyel

## About

Password strength meters tell users whether their password is "strong" when they create it. If a meter rates a password strong when an attacker could easily guess it, the user gets false confidence.

This project measures how often popular meters (zxcvbn, composition rules, libpwquality, passwdqc and Have I Been Pwned) accept guessable passwords. We compare three kinds of passwords: ones chosen by humans, random ones, and ones generated by AI models.

## Project structure

- **Part 1: Theory.** State of the art and evaluation protocol
- **Part 2: Practice.** Implementation and results (in progress).

## Ethics

We use only public password leaks, keep them out of this repository, and publish no credentials.
